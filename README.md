# Python Trading Bot (Binance Futures Testnet)

## Overview
A CLI-based trading bot for Binance Futures (USDT-M) Testnet. Supports Market, Limit, and TWAP orders with robust logging and validation.

## Prerequisites
- Python 3.8+
- Binance Futures Testnet Account
